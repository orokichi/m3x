# Xplore（エクスプロア）

Material 3 Expressive デザインの X (Twitter) クライアント。Next.js 15 + [rettiwt-api](https://github.com/Rishikant181/Rettiwt-API)（X の内部 API）。

> ⚠️ 非公式 API を使うため X の利用規約違反です。アカウント凍結の可能性があるので **サブアカウント** で使ってください。X Corp. とは無関係です。

## 使い方

1. PC のブラウザで x.com にサブアカウントでログイン
2. F12 → Application → Cookies → `https://x.com` から `auth_token` / `ct0` / `twid` の値をコピー
3. Xplore の「設定」画面に貼って「保存して接続テスト」

Cookie はブラウザの localStorage にだけ保存され、リクエストごとにヘッダーで送られます（サーバーには保存・記録しません）。

## 機能

おすすめ / フォロー中タイムライン（無限スクロール）、ポスト詳細と返信スレッド、投稿（テキスト + 画像4枚）、返信・引用、いいね・リポスト・ブックマーク・共有、プロフィール（ポスト/返信/メディア/いいね）、フォロー/解除、フォロー・フォロワー一覧、検索（話題/最新/ユーザー/メディア）、通知、ブックマーク、リスト、日本のトレンド。ライト/ダークはシステム設定に追従。

ログインなしでも、プロフィール・ユーザーのポスト・ポスト詳細・トレンドは見られます。

### パソコン向けレイアウト

- 1280px 以上: ラベル付きナビゲーション、読みやすい幅の中央タイムライン、右カラムに常設の「トレンド / Keep / Groq」パネル
- 1760px 以上: トレンドが独立したカラムに
- 1600px 以上 + 設定「マルチカラム（デッキ）表示」: ホームを TweetDeck 風の複数カラムに（ホーム・フォロー中・検索・リスト・ユーザー・通知・Keep を追加／並べ替え／削除）

### AI（Groq・任意）

設定で自分の Groq API キーを登録すると使えます（キーはこの端末の localStorage のみ）。AI が投稿・いいね・フォローを勝手に行うことはなく、Keep の保存・整理は明示的に頼んだとき／「適用」を押したときだけです。

- 右カラムの Groq: 画面に表示中のポスト（最大7件）について質問
- ポストごと: 要約 / 日本語に翻訳 / 解説・背景 / ファクトチェック観点 / 返信案（下書きを返信欄に入れるだけ）
- スレッド・返信の要約（ポスト詳細）、「ここまでの要約」（ホーム・フォロー・リスト・デッキの各カラム）、トレンドの「なぜ話題?」
- 投稿アシスト: 校正・トーン変更・140字/280字調整・ハッシュタグ提案
- プロフィール分析、Keep への質問とフォルダ分け提案、AI 検索の「次に探す」提案
- 軽い処理は小さく速いモデル、結果はポスト単位でキャッシュ（sessionStorage）してトークンを節約

## 開発

```bash
npm run check   # アイコンのサブセット確認 + テスト（Groq はモック）
node scripts/icons.mjs   # 新しい Material Symbols を使ったら ICONS を再生成
M3X_MOCK_GROQ=1 npm run dev   # Groq を呼ばずにダミー応答で UI を確認
```

## ローカルで動かす（Vercel が X にブロックされたとき）

Vercel などのデータセンター IP は X にブロック/制限されることがあります。その場合は自分の PC で:

```bash
git clone https://github.com/orokichi/m3x.git
cd m3x
npm install
npm run dev   # → http://localhost:3000
```

## エラー

- 「Cookie の期限切れ」: x.com で再ログインして Cookie を取り直す
- 「レート制限」: 15 分ほど待つ
- 「X に拒否されました」: 上のローカル実行を試す
